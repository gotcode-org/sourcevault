# Security Policy

## No Warranty

Per the terms of the AGPL-3.0 license, SourceVault is offered "as is" and 
without any guarantee or warranty pertaining to its operation. While every 
reasonable effort is made by its maintainers to ensure the product remains 
free of security vulnerabilities, users are ultimately responsible for 
conducting their own evaluations of each software release.

## Recommendations

Administrators are encouraged to adhere to industry best practices concerning 
the secure operation of software, such as:

* Ensure Mutual TLS (mTLS) is strictly enforced between all cluster nodes
* Protect and rotate your private Certificate Authority (CA) root keys
* Enforce minimum password complexity and hardware MFA for local accounts
* Prohibit direct access to the internal Git registry and local SQLite databases 
  from untrusted networks
* Keep your deployment updated to the most recent stable release

## Reporting a Suspected Vulnerability

If you believe you've uncovered a security vulnerability and wish to report it 
confidentially, please **DO NOT open a public issue**. 

Instead, you may report it by emailing `security@gotcode.org`. 

Please ensure that your report meets all the following conditions:

* Affects the `main` branch or the most recent stable release of SourceVault
* Affects a SourceVault instance installed and configured per the official docs
* Is reproducible following a prescribed set of clear instructions

Please note that we **DO NOT** accept reports generated by automated tooling 
which merely suggest that a file may be vulnerable under certain conditions.

We will acknowledge receipt of your vulnerability report within 48 hours and 
strive to send you regular updates about our progress. If a fix is required, we 
will issue a patch and a security advisory as quickly as possible.

### Bug Bounties

As SourceVault is provided as free open-source software, we do not offer any 
monetary compensation for vulnerability or bug reports at this time; however, 
your contributions are greatly appreciated and will be publicly credited.
