refactor(core): decouple version variables from cli entrypoints

This pull request refactors the `version` command implementation to completely decouple version state variables from the `cmd` entrypoints, moving them into the `internal/system` domain according to Hexagonal architecture constraints.

- Move `AppVersion`, `Commit`, and `Branch` state into `internal/system/domain.go`.
- Update `Makefile` `LDFLAGS` to inject version data directly into the system package.
- Remove version state variables from `cmd/sourcevault` and `cmd/sourcevaultd`.
- Simplify `GetVersionQuery` to fetch data directly from internal package state instead of requiring struct arguments.
- Check off `TODO` item and update task documentation.
