# Description
Move the version variables (`Version`, `Commit`, `Branch`) out of the `cmd`
package entrypoints and into the `internal/system` domain where they properly
belong. The `Makefile` `-ldflags` injection should target
`gotcode.org/sourcevault/internal/system` instead of `main`.

# Acceptance Criteria
- [x] Removed version variables from `cmd/sourcevault/main.go` and
      `cmd/sourcevaultd/main.go`.
- [x] Added version variables to `internal/system/domain.go`.
- [x] Updated `Makefile` `LDFLAGS` to inject directly into `internal/system`.
- [x] Updated `GetVersionQuery` to remove unnecessary fields and read from
      package state.
- [x] `make check` executes cleanly.

# Implementation Plan
1. Add `AppVersion`, `Commit`, and `Branch` variables to
   `internal/system/domain.go`.
2. Update `Makefile` to set `LDFLAGS` for
   `gotcode.org/sourcevault/internal/system.AppVersion`,
   `gotcode.org/sourcevault/internal/system.Commit`, and
   `gotcode.org/sourcevault/internal/system.Branch`.
3. Update `internal/system/queries.go` to remove struct fields from
   `GetVersionQuery` and fetch the version data directly from the newly
   created package variables in `domain.go`.
4. Delete the variable declarations in `cmd/sourcevault/main.go` and
   `cmd/sourcevaultd/main.go`.
5. Update `cmd/sourcevault/version.go` and `cmd/sourcevaultd/version.go` to
   pass an empty `GetVersionQuery{}`.
6. Run `make check build` to verify the architectural shift compiles and tests
   successfully.
